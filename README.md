# Printer Computers & Systems 🌐💻

Sitio web corporativo de **Printer Computers & Systems**, empresa salvadoreña dedicada a brindar **soluciones tecnológicas integrales** desde el año 2003.

El proyecto presenta información institucional, servicios, marcas con las que se trabaja y un formulario de contacto, con un diseño moderno y profesional.

---

## 🚀 Tecnologías utilizadas

* **Node.js**
* **Express.js**
* **HTML5**
* **CSS / Tailwind CSS**
* **JavaScript**

## ⚙️ Instalación y ejecución local

### 1️⃣ Clonar el repositorio

```bash
git clone https://github.com/USUARIO/REPOSITORIO.git
```

### 2️⃣ Entrar al proyecto

```bash
cd Printer
```

### 3️⃣ Instalar dependencias

```bash
npm install
```

### 4️⃣ Ejecutar el servidor

```bash
node server.js
```

### 5️⃣ Abrir en el navegador

```
http://localhost:3000
```
